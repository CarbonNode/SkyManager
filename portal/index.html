Uploads land straight in the mod folder — the plugin re-scans on every open, so no restart is needed. Portraits are matched by slug from a follower's original name (Olfina Gray-Mane → olfina-gray-mane), so renaming them in the deck never breaks the picture. Everything you change here — a spell icon, a hotkey's name, key, tab or icon, even deleting one — is queued, never written into hotkeys.json: the running game owns that file and rewrites it wholesale. While the game is up it picks a queued change up within a second; with the game closed it lands on the next open (F7 for the deck, F18 for the Spell Deck).
